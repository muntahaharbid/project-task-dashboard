# TaskFlow | تطبيق إدارة المشاريع والمهام

## نبذة عن المشروع

TaskFlow تطبيق ويب تفاعلي باللغة العربية لإدارة المشاريع والمهام ومتابعة التقدم في مساحة عمل واحدة. يركز المشروع على تنفيذ وظائف الواجهة الأمامية دون خادم أو تسجيل دخول، وتُحفظ البيانات محليًا في المتصفح.

## التقنيات المستخدمة

- HTML لبناء هيكل الصفحة والنماذج.
- CSS لتنسيق الواجهة العربية باتجاه RTL ودعم أحجام الشاشات المختلفة.
- JavaScript لإدارة البيانات والتفاعل والتحقق والحفظ.
- Bootstrap RTL لبعض عناصر التصميم.
- Chart.js لإنشاء مخطط حالات المهام.
- `localStorage` لحفظ المشاريع والمهام وتفضيل المظهر على الجهاز الحالي.

تُحمّل Bootstrap وChart.js وخط IBM Plex Sans Arabic من خدمات CDN؛ لذلك يتطلب تحميل هذه الموارد اتصالًا بالإنترنت.

## التشغيل

1. افتح مجلد المشروع في Visual Studio Code أو مستكشف الملفات.
2. افتح `index.html` في متصفح حديث مثل Chrome أو Edge، أو شغّله باستخدام إضافة Live Server إن كانت متاحة.
3. لا توجد أوامر تثبيت أو بناء. يوصى بتوفر اتصال بالإنترنت لتحميل الموارد الخارجية.

إذا تعذر تحميل Chart.js، يعرض التطبيق ملخصًا نصيًا لأعداد المهام حسب الحالة بدل المخطط.

## بنية الملفات

- `index.html`: هيكل لوحة التحكم وأقسام المشاريع والمهام والفلاتر والنماذج.
- `css/styles.css`: الألوان والتخطيط والاستجابة للشاشات الصغيرة والوضع الداكن.
- `js/script.js`: البيانات التجريبية، العرض، التحقق، عمليات الإضافة والتعديل والحذف، البحث والتصفية والفرز والحفظ.
- `دليل-المناقشة.md`: شرح تعليمي لبنية التطبيق وآلية عمله وأسئلة تدريبية للمناقشة.
- `README.md`: وصف المشروع وطريقة تشغيله وميزاته وقيوده.

## الميزات

- لوحة رئيسية تعرض عدد المشاريع والمهام، والمهام المكتملة والمتأخرة، ونسبة الإنجاز.
- مخطط دائري يوضح توزيع المهام بحسب الحالة، مع بديل نصي عند تعذر تحميل المكتبة.
- إضافة المشاريع والمهام وعرضها وتعديلها وحذفها، مع ربط كل مهمة بمشروع.
- حفظ حالة المهمة وأولويتها وتاريخ استحقاقها، والتحقق من الحقول المطلوبة.
- تأكيد قبل الحذف ورسائل للنجاح والأخطاء وحالات النتائج الفارغة.
- بحث فوري، وتصفية حسب المشروع أو الحالة أو الأولوية، وفرز حسب تاريخ الاستحقاق أو التقدم أو الأولوية.
- زر «عرض المهام» في بطاقة المشروع للانتقال إلى قائمة مهامه وتصفية العرض عليها.
- وضع داكن مع حفظ التفضيل، وسحب المهام إلى حالات مختلفة على الكمبيوتر، مع قائمة تغيير حالة مناسبة للمس ولوحة المفاتيح.
- تصميم عربي RTL متجاوب وقائمة جانبية قابلة للطي، مع بيانات تجريبية عند أول تشغيل.

## التخزين والخصوصية

تُخزّن البيانات في `localStorage` في المتصفح الحالي، ولا تُرسل إلى خادم. لا توجد مزامنة بين الأجهزة أو آلية نسخ احتياطي. مسح بيانات الموقع من المتصفح قد يؤدي إلى فقدان المشاريع والمهام. لا تُدخل بيانات شخصية أو سرية.

يقرأ التطبيق أيضًا مفتاح البيانات السابق `taskflow-data` لدعم بيانات النسخة الأولية، ويحفظ البيانات الحالية في `taskflow-data-v2`.

## القيود

- التطبيق واجهة أمامية محلية، ولا يتضمن حسابات مستخدمين أو صلاحيات أو قاعدة بيانات مشتركة.
- موارد التصميم والرسم والخط تعتمد على CDN؛ يعمل بديل نصي عند غياب مكتبة الرسم، لكن الخط والتنسيقات الخارجية قد لا تُحمّل دون إنترنت.
- السحب مخصص لاستخدام الكمبيوتر؛ يتوفر تغيير الحالة من قائمة داخل بطاقة المهمة للأجهزة اللمسية ولوحة المفاتيح.
- نسبة تقدم المشروع محسوبة من نسبة المهام المكتملة، ولا توجد تواريخ بداية أو إدارة لأعضاء الفريق.

## تجربة الاستخدام الأساسية

1. أنشئ مشروعًا من قسم المشاريع.
2. أضف مهمة واربطها بالمشروع، ثم حدد الحالة والأولوية وتاريخ الاستحقاق.
3. جرّب زر «عرض المهام» في بطاقة المشروع، ثم ابحث وصفِّ المهام ورتبها.
4. غيّر حالة مهمة من القائمة أو بالسحب على الكمبيوتر.
5. حدّث الصفحة للتحقق من بقاء البيانات في المتصفح.

تظهر بيانات البداية تلقائيًا عند عدم وجود بيانات محفوظة. حذف قيمة `taskflow-data-v2` من تخزين الموقع عبر أدوات المطور يعيد بيانات البداية، لكنه يمسح البيانات المحلية الحالية.
