# TaskFlow — إدارة المشاريع والمهام

تطبيق عربي بسيط لإدارة مشاريع فريق صغير ومهامه. بُني باستخدام HTML وCSS وJavaScript، مع Bootstrap لتسهيل بعض عناصر التصميم وChart.js للرسم البياني. لا يحتاج إلى خادم أو حساب.

## التشغيل

1. افتحي مجلد المشروع في مستكشف الملفات.
2. افتحي `index.html` في متصفح حديث مثل Chrome أو Edge.
3. يلزم اتصال بالإنترنت لتحميل Bootstrap وChart.js والخط. عند تعذر تحميل Chart.js، يعرض التطبيق أعداد الحالات كنص.

يمكن أيضًا فتح المجلد في VS Code واستخدام إضافة Live Server إن كانت مثبتة. لا توجد أوامر تثبيت أو بناء.

## بنية الملفات

- `index.html`: أقسام الصفحة العربية، نماذج المشاريع والمهام، عناصر الفلترة وإحصاءات اللوحة.
- `css/styles.css`: الألوان والتخطيط RTL واستجابة الهاتف ومظهر الوضع الداكن.
- `js/script.js`: البيانات التجريبية، العرض، التحقق من النماذج، البحث والفرز، الرسم البياني والحفظ.
- `README.md`: تعليمات التشغيل وملخص الاستخدام.

## الميزات

- لوحة تعرض المشاريع والمهام المكتملة والمتأخرة ونسبة الإنجاز، مع مخطط حالات.
- إضافة وتعديل وحذف المشاريع والمهام. حذف مشروع يحذف المهام التابعة بعد تأكيد واضح.
- بحث فوري، وتصفية بالحالة والأولوية، وفرز بالتاريخ أو الحالة أو الأولوية.
- حفظ البيانات واختيار المظهر في `localStorage`، مع بيانات تجريبية عند أول تشغيل.
- قراءة تلقائية لبيانات المفتاح القديم `taskflow-data` في النسخة الأولية.
- وضع داكن، وسحب بطاقة مهمة إلى شريط الحالة المناسب على الكمبيوتر. ويمكن تغيير الحالة من القائمة داخل البطاقة، وهي مناسبة للمس ولوحة المفاتيح.
- تصميم RTL متجاوب، قائمة جانبية قابلة للطي على الكمبيوتر، ونماذج قابلة للاستخدام بلوحة المفاتيح.

## القيود

- البيانات محلية في المتصفح والجهاز الحالي؛ لا توجد مزامنة بين الأجهزة أو نسخ احتياطية.
- يعتمد التصميم والمخطط والخط على موارد CDN، باستثناء عرض نصي بديل للمخطط عند تعذر تحميل Chart.js.
- مناطق السحب متاحة على الكمبيوتر؛ على الهاتف استخدمي قائمة الحالة داخل بطاقة المهمة.
- تقدم المشروع محسوب من نسبة المهام المكتملة، ولا يتضمن أعضاء فريق أو صلاحيات أو تواريخ بداية.

## تجربة سريعة

أضيفي مشروعًا من قسم المشاريع، ثم أضيفي مهمة واربطِيها بالمشروع. جربي البحث والتصفية وتغيير حالة المهمة، ثم حدّثي الصفحة للتأكد من استمرار البيانات. يمكن استعادة بيانات البداية بحذف قيمة `taskflow-data-v2` من تخزين الموقع في أدوات المطور بالمتصفح.
